Rettungsweg

GEC1 · Tag 3 · 13.11.2026

Für alle, bei denen heute etwas fehlt: kein begehbarer Blockout, kein Build, oder das Projekt öffnet gar nicht. Das ist aufzuholen. Dieses Blatt zeigt den kürzesten Weg.

Heute im Kurs bis 14:30, dann wie alle weiter

  1. Projekt öffnet nicht? Im Unity Hub die Version 6000.3.15f1 wählen. Hilft das nicht: das eigene Repository in GitHub Desktop frisch klonen (File › Clone repository) und im Hub hinzufügen. Ohne Repository: auf GitHub die Vorlage macromedia-gec1-ws26 neu verwenden (Use this template).10 min
  2. Läuft das Paket? Kurs-Paket auf 0.3.2 bringen wie auf der Folie, dann Menü Kurs › Setup prüfen. Rote Zeilen jetzt zeigen, nicht später.5 min
  3. Kein Blockout? Tools › Kit › Beispiel „Schlüssel und Tür“ bauen. Die Szene Keller im Project-Fenster mit Strg + D duplizieren und nach dem eigenen Spiel benennen. Sie ist heute der Ersatz-Blockout: ein Boden, eine Tür, eine Spielfigur.3 min
  4. Commit mit der Nachricht „Ersatz-Blockout“, dann Push. Ab hier wird mit allen zusammen gebaut.2 min

Heute zählt, dass Schlüssel und Tür im eigenen Projekt laufen. Den eigenen Raum gibt es in der Woche danach.

In der Woche danach bis Fr 20.11., zusammen etwa 4 Stunden zusätzlich

  1. Der eigene Raum, grau und begehbar. Boden, Wände, eine Tür, der Weg der Spielfigur. Eine Einheit ist ein Meter, eine Tür etwa 2 m hoch. Würfel reichen.bis So 15.11.
    90 min
  2. Die Spec der ersten Interaktion. Vier Zeilen: Verb, Regel, Rückmeldung, Scheitern. Dazu der Satz: Wenn …, und …, dann …bis So 15.11.
    20 min
  3. Interaktion 1 als Graph im eigenen Raum, nach der Drahtliste von Schlüssel und Tür (Handout Tag 3). Vor jedem Experiment ein Commit.bis Mi 18.11.
    60 min
  4. Der Build. File › Build Profiles › Windows › Build. Den Ordner auf den Windows-Rechner der Tauschperson bringen und dort starten. Auf dem Mac: im Hub das Windows-Modul nachinstallieren, Backend Mono.bis Do 19.11.
    30 min
  5. Im Blackboard-Thread: 30-Sekunden-Clip, ein Hindernis, der nächste Schritt. Zwei Sätze ins Devlog, unten in DOKUMENTATION.md.bis Fr 20.11.
    15 min

Damit ist der Meilenstein Blockout eine Woche später erreicht, und der Vertical Slice am 27.11. bleibt in Reichweite: zwei Interaktionen im Blockout.

Wenn es hakt: 30 Minuten selbst suchen (Console von oben lesen, Graph ansehen, Kursseite), dann im Blackboard-Thread fragen, mit Bild der Console und des Graphs: Was wurde versucht, was passiert, was sollte passieren?
