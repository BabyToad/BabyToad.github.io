    Ein Spiel ist eine Schleife

    Jeder Durchlauf ist ein Frame.

    Eure Skripte laufen im zweiten Schritt. Unity ruft dafür in jedem Frame Update auf: bei jedem eingeschalteten Skript auf einem aktiven GameObject, das diese Methode hat.

    Pro Frame oder pro Sekunde?

    tempo = 3;

// in Update()
y += tempo * Time.deltaTime;

    deltaTime ist die Zeit seit dem letzten Frame. Wer damit multipliziert, bewegt Objekte pro Sekunde statt pro Frame. Den Code dazu gibt es unten im Selbststudium.

    Was ein GameObject kann

    Ein GameObject ist zunächst leer. Jede Component gibt ihm eine Fähigkeit.

    Jede Component hat im Inspector ihre eigenen Einstellungen. Auch ein Skript ist eine Component.

    Git ist euer Rückgängig-Knopf

    Ein Commit ist ein Speicherpunkt. Geht etwas kaputt, springt ihr dorthin zurück.

    Noch nicht committet? In GitHub Desktop: Discard.

    Agenten committen nur, wenn ihr darum bittet, und gepusht wird nur auf ausdrückliche Anweisung. So bleibt ein Mensch im Kreislauf, bis ihr einschätzen könnt, wann ein Agent das Steuer übernehmen darf.

    Das KI-Verzeichnis

    Jede Änderung, die eine KI im Projekt macht, bekommt eine Zeile.

    Pflicht, auch ohne KI-Nutzung.

    Richtlinie der Hochschule vom 28.04.2025: Das Verzeichnis gehört in den Anhang der PDF. Reine Fragen ohne Änderung kommen nicht hinein, außer ihr verwendet die Antwort. Der Agent kann die Zeile eintragen; ihr prüft sie.

    HIGH WATER

    Ein Prügelspiel mit Physik. Das Gebäude ist der zweite Gegner.

    Wie Streets of Rage, mit der Physik von Smash Bros.

    Alles im Raum ist Waffe

    Jede Wand ist Mauerwerk. Jeder Gegner ist ein Wurfgeschoss.

    Was schiefgehen kann

    Der Dreier-Schlag muss sich allein schon gut anfühlen.

    Sonst trägt die ganze Physik nichts. Also kommt er zuerst.

    Die Pitch-Karte zu HIGH WATER

    • Erlebnis: Jeder Treffer sitzt, und der Raum geht dabei kaputt.
    • Machbarkeit: Ein Stockwerk, eine Gang, ein Boss. Keine Story.
    • Riskanteste Annahme: Der Dreier-Schlag trägt das Spiel. Also zuerst bauen und zuerst testen.

    Für Neugierige: der erste Würfel

    Optional

    Ein Würfel, ein Skript, eine Zeile in Update.

    Würfel anlegen, Skript Mover anlegen, auf den Würfel ziehen, Play.

    Wie schnell steigt der Würfel?

    void Update()
{
    transform.Translate(0, 0.05f, 0);
}

    Pro Frame 0,05. Bei 30 Frames pro Sekunde sind das 1,5 pro Sekunde, bei 144 Frames pro Sekunde 7,2.

    Pro Sekunde statt pro Frame

    // vorher: pro Frame
transform.Translate(0, 0.05f, 0);

// jetzt: pro Sekunde
float weg = 3f * Time.deltaTime;
transform.Translate(0, weg, 0);

    Ohne deltaTime gilt Bewegung pro Frame, mit deltaTime pro Sekunde.
