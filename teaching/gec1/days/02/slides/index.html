    Kurz zurück: deltaTime

    Wer hat den Würfel zu Hause bewegt?

    Ohne deltaTime steigt er pro Frame, auf schnellen Rechnern also schneller. Mit deltaTime steigt er pro Sekunde, überall gleich.

    Zwei Minuten pro Pitch

    2:00

    Die Uhr ist hart. Danach schreibt jede Person eine Pitch-Karte. Diskutiert wird nicht.

    Die Reihenfolge ist ausgelost. Wer dran ist, steht schon bereit.

    Die Pitch-Karte

    Eine Karte pro Pitch. Am Ende bekommt jede Person die Karten zu ihrem eigenen Pitch.

    Ihr baut ein Erlebnis

    Ihr baut Straße und Auto. Fahren tun die Spielenden.

    Darum gilt: Was das Spiel erzählt, sollen die Spielenden auch tun.

    Ideen, schwach und stark

    Schwach: „Ein Open-World-Spiel mit Crafting, Dialogen und Bosskämpfen.“

    Stark: „Eine Leuchtturmwärterin, eine Sturmnacht, drei Schiffe. Man dreht nur das Licht.“

    Stark heißt: ein Erlebnis, eine Handlung, eine Grenze.

    Lieber eine Sache richtig

    • Klein und fertig schlägt groß und kaputt
    • Die letzten 20 % der Arbeit kosten 80 % der Zeit
    • Jedes Feature muss gebaut, getestet und erklärt werden

    Kursstandard: ein Raum, eine Kernschleife, zwei Interaktionen, ein Neustart. Feature-Freeze am 11.12.

    Von der Idee zur Spec

    1. Verb: Was tun die Spielenden?
    2. Regel: Nach welchen Regeln?
    3. Rückmeldung: Woran merken sie, dass es geklappt hat?
    4. Scheitern: Was passiert, wenn es schiefgeht?

    Eine Spec (Spezifikation) ist gut, wenn jemand anderes sie bauen kann, ohne nachzufragen.

    Eine Spec zerlegen

    Schwach

    „Der Spieler kann Gegner besiegen.“

    Lasst die Spec prüfen

    „Was ist an dieser Spec mehrdeutig? Schreib sie nicht um.“

    Der Agent fragt nach. Ihr entscheidet und schreibt.

    Blockout: grau, aber begehbar

    Erst stimmen Größen und Wege, dann kommt die Grafik.

    Würfel, Ebenen, ProBuilder: mehr braucht ein Blockout nicht.

    Eine Einheit ist ein Meter

    Stellt zuerst die Spielfigur hinein. Dann seht ihr, ob der Rest passt.

    Die Spielfigur ist schon da

    Aus dem Kurspaket: Spieler in die Szene ziehen, Play, laufen.

    • WASD laufen, Maus schauen
    • Leertaste springen, Shift rennen
    • V wechselt zwischen Ego- und Third-Person-Ansicht

    Fällt die Figur aus der Welt, erscheint sie wieder am Start. Ein Gamepad geht auch.

    Transform: lokal und Welt

    Ein Transform hält Position, Drehung und Größe, je als Vektor mit x, y und z.

    Hängt ein Objekt an einem anderen, sind seine Werte lokal: Es bewegt sich mit dem Elternobjekt mit. Die Weltkoordinaten zählen von der Mitte der Szene.

    Prefab und Instanzen

    Ein Prefab: einmal bauen, oft verwenden, an einer Stelle ändern.

    Ein Prefab ist eine Vorlage für ein GameObject mit allen Komponenten. Änderungen am Prefab wirken auf alle Instanzen in der Szene, außer dort, wo eine Instanz einen Override hat.

    Heute schon ein Build

    Ein Build läuft ohne Unity. Bis zum 13.11. muss eurer auf einem fremden Windows-Rechner laufen.

    File › Build Profiles › Windows › Build

    Mac: im Hub das Windows-Modul dazuholen, Backend Mono.

    Der Build kommt bewusst früh, damit Probleme nicht erst im Januar auffallen. Auf dem Mac geht für Windows nur das Mono-Backend, IL2CPP nicht. Wer kein Windows-Gerät hat, tauscht mit einer Person aus dem Kurs.

    Was nie ins Repository gehört

    Das Repository hält nur, was ihr selbst gemacht habt.

    • Library, Temp, Logs: baut Unity neu
    • Builds: gehören in die Abgabe
    • Dateien über 50 MB
    /Library/
/Temp/
/Logs/
/Build/

    History: jeder Commit mit Nachricht.

    Die .gitignore der Vorlage hält diese Ordner schon heraus. GitHub warnt bei Dateien über 50 MB und lehnt sie ab 100 MB ab. In GitHub Desktop zeigt der Reiter History jeden Commit von heute: Gute Nachrichten sagen, was und warum, nicht „update“.

    Checkpoint

    1. Die Spielfigur läuft durch einen grauen Raum
    2. Die Spec der ersten Interaktion steht
    3. Committet und gepusht
    4. Ein Build existiert

    Was fehlt, ist eure Aufgabe für die nächsten 48 Stunden.

    3. Wer 30 Minuten feststeckt, fragt
    4. Bis zum 13.11.: testen, Spec überarbeiten
