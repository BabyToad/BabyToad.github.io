Component

Ein Baustein an einem GameObject mit eigenen Einstellungen. Transform, Renderer, Collider und eigene Skripte sind Komponenten.

Markdown

Kurz

Eine Component gibt einem GameObject eine Fähigkeit. Im Inspector erscheint jede als eigener Kasten mit Einstellungen.

Componentmacht
TransformPosition, Drehung, Größe
Mesh Renderersichtbar machen
ColliderForm für Kollisionen
Rigidbodyvon Physik bewegen lassen
eigenes Skripteigenes Verhalten

Genauer

Ein Skript wird zur Component, indem es von MonoBehaviour erbt. Dann lässt es sich mit Add Component an ein Objekt hängen, und Unity ruft seine Methoden wie Update auf.

Objekte bekommen ihr Verhalten aus der Kombination ihrer Komponenten. Ein Würfel mit Collider und Rigidbody fällt; ohne Rigidbody bleibt er stehen.
