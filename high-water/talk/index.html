§1 OrganisationManagement

Running agents is project management

Briefs
Every task states date, branch, goal and rules.
Freezes
No new features after Saturday 22:00. Sunday is for polish.
Handoffs
Work changes hands through a shared message board.
Shared resources
One PC: agents queue for it with "machine yours" / "machine free".
The lead's job is integration and judgement, not typing.
§1 OrganisationIdentity

One member, one model

Why
A name only means something if the same model stands behind it all week.
What happened
Mid-jam, a tool quietly switched its default model. Members could have been swapped unnoticed.
The rule
Pin the model on every call. Write each member's model down.
Consistent identity makes credit, review standards and the retrospective honest.

§3 of 5Documents
03

Shared documents are the team's memory

Anyone, human or agent, can catch up on where we are, why we decided things, and where we're going.

§3 DocumentsThe four documents

Four documents held the project

Design notebook
Every decision and the reason for it.
Handoff
"Resume here": what's live, what's open, who does what.
Devlog
Jam rules, deadlines and the release checklist.
Review files
Every code review, kept so fixes can point to them.
Each document has exactly one owner.
§3 DocumentsThe failure mode

Documents go stale. Agents forget.

Stale notes
Saturday morning, the handoff still described Friday night.
Lost memory
Long-running agents compress their memory. One did so three times in a day.
The fix
The code is the truth. Restart long-running agents with a written brief.
"Another copy of me has clearly been doing that work."An agent after memory loss, about its own work from minutes earlier
For non-technical listeners: it's a shift handover in a hospital. The handover note is everything.
§4 of 5Quality
04

If agents make code cheap, review has to be expensive

With agents doing the typing, there's no excuse for low standards.

§4 QualityThe process

A second AI checks every change

Different model
Claude agents wrote the code. A Codex agent reviewed it.
Three verdicts
Merge, merge with fixes, or hold. Nothing went public on hold.
Tests that play
Agents can't play the game, so ~140 automated scenes play it for them.
24 review rounds in one week.
§4 QualityWhat it caught

Bugs the reviewer caught and the tests missed

Wrong target
A tumbling enemy was measured from the wrong point, 1.3 m off.
Wetting that stalls
The sprinklers could stop wetting the floor forever.
Lost score
Kills vanished from the score when a body disappeared early.
Missing hit
Two explosions reaching one enemy could drop a hit.
§4 QualityExample: one expensive attack

Making one attack 2.4× cheaper

Every speed-up introduced a subtle bug. Review caught each one before players did.
Desktop, one staff discharge into a canal with three thugs. Steps: water tell only; hitstop deferred; lazy pose; plan tables; r22 fixes. Eight review rounds.
§4 QualityHonest tests
"The [test] would then pass the exact cost it was built to catch."
An agent, refusing to loosen a failing performance test
A failing test is information. A test adjusted until it passes is decoration.
§5 of 5Failures
05

What went wrong

In plain language.

§5 FailuresIncident log

Four things that went wrong

Forgetting
Agents lose their memory over long sessions. Handover notes, not hope.
Rules on paper
Written rules got bent. Enforce them with tools, not paragraphs.
One computer
Twenty workers, one PC: crashes, queues, skewed measurements.
Scope
A full building simulation in a jam week. It worked, and it was expensive.
§5 FailuresThe jam

Disqualified, and that was fair

The rule
The jam banned AI-generated assets, to keep it fair for amateurs.
What we did
Our assets were written as code by AI. We disclosed all of it.
The lesson
The "ask the organisers" item sat on our checklist all week.
Clarify the rules before you build on them.
Appendix Godot1 of 2 · testing

Godot: testing with agents

Headless scenes
Small test scenes that play, check and print one line. Run them one at a time.
The clock trap
--fixed-fps runs game time unpaced. Don't mix it with real time in a test.
Defer the extras
Show the hit this frame. Build the extra effects next frame, before drawing.
Appendix Godot2 of 2 · Web

Godot: shipping to the Web

First draw
Shader compiles stall the browser. One shader and a warm-up took the level select from 6 s to 1.7 s.
What ships
The export bundles every JSON file. Exclude internal data on purpose.
All as code
Models, music, sound, UI: all written as code. A great constraint, and why we were disqualified.
